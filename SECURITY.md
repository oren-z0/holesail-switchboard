# Security Policy

## Supported Versions

Only the latest released version of holesail-switchboard receives security updates.

| Version | Supported |
| ------- | --------- |
| Latest  | Yes       |
| Older   | No        |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately by email:

**orenz0@protonmail.com**

Please do **not** open a public GitHub issue for security vulnerabilities.

When reporting, please include:

- A description of the vulnerability and its potential impact
- Steps to reproduce the issue
- The affected version(s)
- Any suggested fix or mitigation, if available

You should receive a response within a few days. Once the issue is confirmed, a fix will be prepared and released, and you will be credited for the discovery unless you prefer to remain anonymous.
